RD Homemaster – VIP Website
===========================

Diese ZIP ist als fertige statische GitHub-Pages-Website aufgebaut.

WICHTIG BEIM HOCHLADEN AUF GITHUB
1. ZIP auf dem PC entpacken.
2. Den INHALT des Ordners in das Stammverzeichnis des Repositories hochladen – nicht die ZIP-Datei selbst.
3. Die Datei CNAME muss im Stammverzeichnis erhalten bleiben. Sie enthält: www.rd-homemaster.de
4. Danach den Commit bestätigen.
5. Nach Veröffentlichung www.rd-homemaster.de mit Strg+F5 neu laden.
